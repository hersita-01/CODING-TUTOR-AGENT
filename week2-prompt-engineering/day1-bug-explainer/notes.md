# Day 1 Notes: Bug Explainer

Goal: practice system vs user prompts for a beginner-friendly debugging tutor.

What this prompt should do:
- Explain what an error means in plain English.
- Explain why the learner's code caused it.
- Avoid giving corrected code immediately.
- End with one guiding question.

Useful system-prompt rule:
The tutor should be calm, encouraging, and specific about the error without solving the full task for the learner.
