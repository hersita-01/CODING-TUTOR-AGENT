# Day 2 Notes: Few-Shot Prompting

Goal: teach the model the difference between a helpful Socratic hint and an answer-revealing fix.

Good examples:
- Point to the idea the learner should inspect.
- Ask one question.
- Avoid corrected code.

Bad example:
- Directly says what line to change.
- Removes the learner's chance to reason.

Takeaway:
Few-shot examples are useful when instructions alone are too vague. Showing both good and bad responses makes the tutor's behavior clearer.
