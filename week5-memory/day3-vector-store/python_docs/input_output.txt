# Input and Output in Python
topic: input_output
difficulty: beginner

## Introduction

Programs need to communicate with users: displaying information and accepting typed input. Python provides simple built-in functions, print() and input(), for these tasks.

## Concept Overview

print() displays text or values on the console. input() pauses execution, waits for the user to type, and always returns a string. F-strings let you embed variables directly inside a string using curly braces, making output easy to format.

## Syntax

print(value1, value2, ...)

variable_name = input("prompt message")

## Explanation

print() accepts multiple comma-separated arguments and supports sep and end parameters to control spacing and line endings. input() always returns a string, so numeric input must be converted with int() or float() before use in calculations.

## Example 1

Code:

name = input("Enter your name: ")
age = int(input("Enter your age: "))

print(f"Hello, {name}! You are {age} years old.")

Explanation:

Collects a name as a string and an age converted to int right away. The f-string embeds both variables directly into the message.

Output:

Enter your name: Alice
Enter your age: 22
Hello, Alice! You are 22 years old.

## Example 2

Code:

length = float(input("Enter length: "))
width = float(input("Enter width: "))

area = length * width

print("Area:", area)
print("Length:", length, "Width:", width, sep=" | ")

Explanation:

Converts both inputs to floats for decimal precision, then calculates area. The second print shows the sep parameter changing the default separator.

Output:

Enter length: 5.5
Enter width: 3.2
Area: 17.6
Length: 5.5 | Width: 3.2

## Common Beginner Mistakes

Forgetting that input() always returns a string leads to string concatenation instead of addition. Missing or unclear prompts confuse users about expected input. Beginners also forget each print() starts a new line by default.

## Debugging Tips

If output looks wrong, especially unexpected concatenation, check whether input was converted with int() or float(). Review the sep and end parameters if formatting looks off.

## Best Practices

Write clear prompts inside input(). Convert input to the right type immediately after receiving it. Prefer f-strings over string concatenation for readable output.

## Interview Questions

Question 1: What data type does input() return.
Answer: Always a string, regardless of what the user types.

Question 2: How do you print multiple values on the same line.
Answer: Pass multiple arguments to print, or change the end parameter.

Question 3: What is an f-string.
Answer: A formatted string literal that embeds variables using curly braces.

Question 4: How do you convert input into a float.
Answer: Wrap it with float(), for example float(input("Enter value: ")).

Question 5: What does the sep parameter control.
Answer: The separator string placed between values passed to print, a space by default.

## Summary

input() and print() enable interactive programs. Always convert input to the needed type and use f-strings for clean, readable output formatting.
