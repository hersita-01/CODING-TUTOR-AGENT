# Lists in Python
topic: lists
difficulty: beginner

## Introduction

A list stores an ordered collection of items in Python. Lists are flexible — they can hold mixed data types and be modified after creation.

## Concept Overview

Lists are written in square brackets with comma-separated items. Being mutable, you can add, remove, or change elements after creation. Lists support indexing (position-based access) and slicing (extracting a range). Built-in methods like append, remove, and sort make manipulation easy.

## Syntax

list_name = [item1, item2, item3]

list_name[index]

## Explanation

Indexing starts at 0; negative indices count from the end, with -1 being the last item. Slicing uses a colon to extract a range. append() adds to the end, insert() adds at a position, and remove() deletes the first matching value.

## Example 1

Code:

fruits = ["apple", "banana", "cherry"]

fruits.append("mango")
fruits.insert(1, "orange")

print("Updated list:", fruits)
print("First element:", fruits[0])
print("Last element:", fruits[-1])
print("Sliced list:", fruits[1:3])

Explanation:

append() adds mango to the end; insert() places orange at index 1. Indexing grabs the first and last items; slicing extracts indices 1 and 2.

Output:

Updated list: ['apple', 'orange', 'banana', 'cherry', 'mango']
First element: apple
Last element: mango
Sliced list: ['orange', 'banana']

## Example 2

Code:

numbers = [45, 12, 78, 3, 25]

numbers.sort()
print("Sorted list:", numbers)

total = 0
for num in numbers:
    total += num

average = total / len(numbers)
print("Average:", average)

Explanation:

sort() arranges numbers ascending in place. A for loop sums all values, then average divides the total by the count from len().

Output:

Sorted list: [3, 12, 25, 45, 78]
Average: 32.6

## Common Beginner Mistakes

Forgetting indexing starts at 0 causes off-by-one errors. Accessing an invalid index raises an IndexError. Confusing append with extend, and assuming simple assignment copies a list, are also common mistakes — it just creates a second reference.

## Debugging Tips

On an IndexError, print len(list) to confirm valid index ranges. If a list changes unexpectedly, check whether it was copied by assignment instead of .copy().

## Best Practices

Use descriptive names like student_names. Use .copy() or list() for independent copies. Prefer list comprehensions over manual loops for building new lists.

## Interview Questions

Question 1: What is the difference between a list and a tuple.
Answer: Lists are mutable; tuples are immutable.

Question 2: How do you access the last element without knowing the length.
Answer: Use negative indexing, fruits[-1].

Question 3: What's the difference between append and extend.
Answer: append adds one item; extend adds each item of an iterable individually.

Question 4: What happens accessing a nonexistent index.
Answer: Python raises an IndexError.

Question 5: How do you copy a list independently.
Answer: Use .copy() or list(list_name).

## Summary

Lists are mutable, ordered collections with rich built-in methods. Watch for index errors and shared references when copying.
