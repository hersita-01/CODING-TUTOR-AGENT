# Loops in Python
topic: loops
difficulty: beginner

## Introduction

Loops repeat a block of code, useful for processing collections or repeating calculations. Python has two loop types: for loops and while loops.

## Concept Overview

A for loop iterates over a sequence like a list, string, or range, running once per element. A while loop repeats as long as a condition stays True, useful when the number of iterations isn't known ahead of time. break exits a loop immediately; continue skips to the next iteration.

## Syntax

for item in sequence:
    statement

while condition:
    statement

## Explanation

for loops handle iteration automatically, often paired with range() for a fixed count. while loops require you to manually update the condition variable — forgetting this causes an infinite loop, a common and important mistake.

## Example 1

Code:

fruits = ["apple", "banana", "cherry"]

for fruit in fruits:
    print("I like", fruit)

for number in range(1, 4):
    print("Number:", number)

Explanation:

The first loop iterates directly over a list. The second uses range(1, 4) to generate numbers 1 through 3, since the stop value is exclusive.

Output:

I like apple
I like banana
I like cherry
Number: 1
Number: 2
Number: 3

## Example 2

Code:

count = 0

while count < 5:
    if count == 3:
        count += 1
        continue
    print("Count is:", count)
    count += 1

print("Loop finished.")

Explanation:

Runs while count is under 5. When count equals 3, continue skips the print for that iteration after incrementing, moving to the next check.

Output:

Count is: 0
Count is: 1
Count is: 2
Count is: 4
Loop finished.

## Common Beginner Mistakes

Forgetting to update the while condition's variable causes an infinite loop. Modifying a for loop's variable inside the body has no effect on iteration. Confusing break with continue, and off-by-one errors with range(), are also common.

## Debugging Tips

If a loop runs forever, check that the while condition's variable updates correctly inside the loop. Print the sequence from range() to confirm it matches expectations.

## Best Practices

Prefer for loops when the number of iterations is known. Reserve while loops for condition-based repetition. Always ensure while loop variables update properly to avoid infinite loops.

## Interview Questions

Question 1: What is the main difference between for and while loops.
Answer: for iterates a known sequence; while repeats based on a condition.

Question 2: What does break do.
Answer: It immediately terminates the loop.

Question 3: What does continue do.
Answer: It skips the rest of the current iteration and moves to the next.

Question 4: What causes an infinite loop.
Answer: A while condition that never becomes False, often from an unupdated variable.

Question 5: What does range() do in a for loop.
Answer: Generates a sequence of numbers to iterate over.

## Summary

for loops suit known sequences; while loops suit condition-based repetition. Watch for infinite loops and off-by-one errors with range().
