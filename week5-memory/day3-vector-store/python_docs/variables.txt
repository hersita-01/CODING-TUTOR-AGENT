# Variables in Python
topic: variables
difficulty: beginner

## Introduction

A variable is a name that stores a value in memory. Variables let you save, reuse, and update data in your program. In Python, you create one simply by assigning a value to a name — no type declaration needed.

## Concept Overview

Python creates a variable the instant you assign it a value. Python is dynamically typed, meaning types are never declared — they're inferred from the value. A variable name is really a reference pointing to an object in memory. Reassigning a variable makes it point to a new object; it does not change the old one.

## Syntax

variable_name = value

You can assign multiple variables in one line, or give several variables the same value at once.

## Explanation

Names may contain letters, digits, and underscores, but cannot start with a digit. Names are case-sensitive, so age and Age differ. Keywords like if or class cannot be used as names. Prefer clear names such as student_age over a.

## Example 1

Code:

student_name = "Alice"
student_age = 20
is_enrolled = True

print("Name:", student_name)
print("Age:", student_age)
print("Enrolled:", is_enrolled)

Explanation:

Three variables store a name, age, and enrollment status. Python infers each type automatically. print() displays each value with a label.

Output:

Name: Alice
Age: 20
Enrolled: True

## Example 2

Code:

x = 10
y = 5
sum_result = x + y
x, y = y, x

print("Sum:", sum_result)
print("After swap, x:", x)
print("After swap, y:", y)

Explanation:

This adds two variables, then swaps their values using x, y = y, x — a shortcut that avoids a temporary variable.

Output:

Sum: 15
After swap, x: 5
After swap, y: 10

## Common Beginner Mistakes

Using a variable before assigning it causes a NameError. Invalid names — starting with a digit or containing spaces — cause a SyntaxError. Confusing = with == is common, as is accidentally reusing variable names for different purposes.

## Debugging Tips

If you get a NameError, check for typos and confirm the variable was assigned before use. Print variable values at different points to verify they hold what you expect.

## Best Practices

Use descriptive, snake_case names like student_age. Avoid single letters except in short loops. Keep names consistent and don't reuse the same name for different purposes.

## Interview Questions

Question 1: What is a variable in Python.
Answer: A name that refers to a value stored in memory, created when you assign it a value.

Question 2: Does Python require you to declare a variable's type.
Answer: No, Python is dynamically typed and infers the type from the assigned value.

Question 3: What happens if you use a variable before assigning it.
Answer: Python raises a NameError because the variable doesn't exist yet.

Question 4: Can a variable's type change during execution.
Answer: Yes, reassigning a variable to a different value changes its type too.

Question 5: What naming convention does Python recommend.
Answer: snake_case — lowercase words separated by underscores, per PEP 8.

## Summary

Variables in Python are dynamically typed references created by assignment. Use clear snake_case names, avoid undefined variables, and follow PEP 8 for cleaner code.
