# If Else Statements in Python
topic: if_else
difficulty: beginner

## Introduction

Decision making lets a program run different code depending on conditions. Python uses if, elif, and else to implement this logic clearly and readably.

## Concept Overview

if runs a block only when its condition is True. elif checks another condition if earlier ones were False. else runs when none of the previous conditions matched. Python uses indentation, not braces, to define which statements belong to each block.

## Syntax

if condition1:
    statement1
elif condition2:
    statement2
else:
    statement3

## Explanation

Conditions must evaluate to True or False. Python checks them in order and stops at the first True condition, running only that block. Conditionals can nest, and comparison or logical operators often combine multiple criteria into one decision.

## Example 1

Code:

marks = 75

if marks >= 90:
    grade = "A"
elif marks >= 75:
    grade = "B"
elif marks >= 60:
    grade = "C"
else:
    grade = "F"

print("Grade:", grade)

Explanation:

Checks marks against each threshold in order. 90 fails, 75 passes, so grade becomes B and the rest of the chain is skipped.

Output:

Grade: B

## Example 2

Code:

age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("Entry allowed.")
elif age < 18:
    print("Entry denied due to age restriction.")
else:
    print("Entry denied. Ticket required.")

Explanation:

Combines a comparison with the and operator — both age and has_ticket must be satisfied for the first branch to run.

Output:

Entry allowed.

## Common Beginner Mistakes

Forgetting the colon after if/elif/else causes a SyntaxError. Inconsistent indentation causes an IndentationError. Using = instead of == inside a condition is also a common syntax mistake.

## Debugging Tips

Print the condition itself before the if statement to check whether it's True or False. Watch indentation carefully, especially in nested conditionals.

## Best Practices

Keep conditions simple; use named boolean variables for complex logic. Prefer elif chains over multiple separate if statements when only one branch should run. Avoid deep nesting.

## Interview Questions

Question 1: What is the purpose of elif.
Answer: It checks another condition if the previous if or elif was False.

Question 2: How does Python define an if block.
Answer: Through indentation, not curly braces.

Question 3: What happens if no condition is True and there's no else.
Answer: No block runs; execution continues after the conditional.

Question 4: Can if statements be nested.
Answer: Yes, an if can contain another if inside its block.

Question 5: What type must a condition evaluate to.
Answer: A boolean value, True or False.

## Summary

if, elif, and else implement decision-making in Python. Correct indentation and clear conditions are essential for reliable conditional logic.
