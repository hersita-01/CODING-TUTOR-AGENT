# Modules in Python
topic: modules
difficulty: beginner

## Introduction

As programs grow, keeping all code in one file becomes impractical. Modules — files of reusable Python code — help organize and reuse logic across programs.

## Concept Overview

A module is any .py file containing functions, classes, or variables. Python's standard library includes modules like math, random, and datetime. You can also write your own modules and import them elsewhere, keeping projects organized and reusable.

## Syntax

import module_name

from module_name import function_name

## Explanation

After import module_name, access its contents with dot notation. from module_name import function_name lets you use that function directly, without a prefix. as lets you assign a shorter alias, like numpy as np.

## Example 1

Code:

import math

radius = 5
area = math.pi * math.pow(radius, 2)

print("Value of pi:", math.pi)
print("Area of circle:", area)
print("Square root of 16:", math.sqrt(16))

Explanation:

Imports the built-in math module, using its pi constant, pow(), and sqrt() functions, all accessed with the math. prefix.

Output:

Value of pi: 3.141592653589793
Area of circle: 78.53981633974483
Square root of 16: 4.0

## Example 2

Code:

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

from calculator import add, subtract

result1 = add(10, 5)
result2 = subtract(10, 5)

print("Addition result:", result1)
print("Subtraction result:", result2)

Explanation:

Defines add and subtract in a separate calculator.py module, then imports both functions directly into another script and calls them without a module prefix.

Output:

Addition result: 15
Subtraction result: 5

## Common Beginner Mistakes

Importing a nonexistent or misspelled module causes ModuleNotFoundError. Naming your own file the same as a standard module, like random.py, can shadow the real one. Importing an entire module for just one function adds unnecessary prefixing.

## Debugging Tips

On ModuleNotFoundError, check spelling and confirm the package is installed via pip. If a built-in module behaves oddly, check for a same-named local file shadowing it.

## Best Practices

Import only what you need with from import. Use standard aliases where common. Organize related code into well-named custom modules as projects grow.

## Interview Questions

Question 1: What is a module in Python.
Answer: A file containing reusable Python code like functions and classes.

Question 2: Difference between import and from import.
Answer: import needs a dot-notation prefix; from import brings the item in directly.

Question 3: What error occurs if a module can't be found.
Answer: ModuleNotFoundError.

Question 4: Why use the as keyword when importing.
Answer: To give the module a shorter or conventional alias.

Question 5: What happens if you name a file the same as a standard module.
Answer: Python may import your local file instead, causing unexpected behavior.

## Summary

Modules organize reusable Python code. Import only what you need and avoid naming conflicts with standard library modules.
