# Operators in Python
topic: operators
difficulty: beginner

## Introduction

Operators are symbols that perform operations on values, called operands. They power nearly every computation and decision in a program, from arithmetic to conditional logic.

## Concept Overview

Python has arithmetic operators for math, comparison operators for evaluating relationships, logical operators for combining boolean expressions, assignment operators for storing values, and membership operators for checking if a value exists in a sequence. Operator precedence controls the order operations run in.

## Syntax

result = operand1 operator operand2

Example: a + b for addition, a == b for equality comparison.

## Explanation

Arithmetic operators: +, -, *, /, //, %, **. Comparison operators (==, !=, >, <) return booleans. Logical operators and, or, not combine conditions. Assignment shortcuts like += update in place. in and not in test membership in a sequence.

## Example 1

Code:

a = 15
b = 4

print("Addition:", a + b)
print("Floor Division:", a // b)
print("Modulus:", a % b)
print("Exponentiation:", a ** 2)
print("Is a greater than b:", a > b)

Explanation:

Shows arithmetic and comparison operators together: addition, floor division, modulus (remainder), exponentiation, and a greater-than comparison returning a boolean.

Output:

Addition: 19
Floor Division: 3
Modulus: 3
Exponentiation: 225
Is a greater than b: True

## Example 2

Code:

age = 20
has_id = True

can_enter = age >= 18 and has_id

print("Can enter:", can_enter)

age += 1
print("Updated age:", age)

Explanation:

Combines a comparison with the and logical operator — both conditions must be true. += then increments age by one as a shorthand for age = age + 1.

Output:

Can enter: True
Updated age: 21

## Common Beginner Mistakes

Confusing = (assignment) with == (comparison) causes a SyntaxError in conditions. Misunderstanding operator precedence leads to wrong results without parentheses. Beginners also confuse the logical and with the bitwise & operator.

## Debugging Tips

Break complex expressions into smaller parts and print each one to isolate issues. Use parentheses generously to make the intended order of operations explicit.

## Best Practices

Use parentheses to clarify order of operations, especially when mixing arithmetic, comparison, and logical operators. Avoid comparing floats directly with == due to precision issues.

## Interview Questions

Question 1: What is the difference between = and == in Python.
Answer: = assigns a value; == compares two values for equality.

Question 2: What does the modulus operator return.
Answer: The remainder of a division between two numbers.

Question 3: What is the difference between and and or.
Answer: and requires both conditions true; or requires at least one.

Question 4: What does the membership operator in do.
Answer: Checks whether a value exists within a sequence like a list or string.

Question 5: What is operator precedence.
Answer: The rules that determine the order operations are evaluated in an expression.

## Summary

Operators drive calculations, comparisons, and logic in Python. Understand precedence and avoid confusing assignment with comparison to write correct expressions.
